# Telegram Ads — проверка функциональности @islogix_bot

## BotFather /setcommands (вставить одним сообщением)
```
start - Главное меню и выбор маршрута
help - Справка: что делает бот и как получить расчёт
track - Отследить отправление по номеру DBxxxx
menu - Вернуться в главное меню
```
(Админ-команды /orders, /order, /status в публичный список не добавлять.)

## Проверка
1. `/start` → приветствие + 4 inline-кнопки маршрутов + меню. Вопроса «Из какого города» нет.
2. https://t.me/islogix_bot?start=dokumenty → «Вы пришли с витрины» + те же кнопки.
3. https://t.me/islogix_bot?start=ua_ru → «Маршрут: Украина → Россия. Из какого города отправляем?» (аналогично ua_by, ru_ua, by_ua).
4. `/help` → справка; запрещены паспорта, ID-карты, военные билеты.
5. `asdkjh` или `/foo` → «Извините, я не понял…» + меню + подсказка /start /help.
